# movodo_custom_parts
A collection of my MoVoDo 3D printer parts (Monolith, Voron, DoomCube) 


## 4040_Panel_Mount.FCStd
- Allows the mount of panels without disassembling the frame (When using 4040 vertical and 4020/4040 horizontal profiles)
- Parametric (Values spreadsheet)
- FreeCAD
